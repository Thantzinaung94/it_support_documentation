# CCTV (Closed-Circuit Television) Documentation

## Introduction

CCTV (Closed-Circuit Television) is a video surveillance system used to monitor and record activities in homes, offices, schools, banks, shops, factories, and public areas. Unlike broadcast television, CCTV signals are transmitted to a limited set of monitors and recording devices for security and monitoring purposes.

Modern CCTV systems help improve safety, prevent theft, monitor operations, and provide evidence during incidents.

---

# What is CCTV?

CCTV is a surveillance technology that uses cameras to capture video footage and transmit it to recording systems or monitors.

Common uses include:

- Home security
- Office monitoring
- Traffic surveillance
- Industrial monitoring
- Public safety
- Access control

---

# Types of CCTV Cameras

## 1. Dome Camera

Dome cameras are commonly installed indoors and are mounted on ceilings.

### Features
- Compact design
- Wide viewing angle
- Difficult to identify viewing direction

### Common Usage
- Offices
- Shops
- Hotels
- Schools

## 3. PTZ Camera (Pan-Tilt-Zoom)

# Main Components of a CCTV System

| Component | Description |
|---|---|
| Camera | Captures video footage |
| DVR/NVR | Records and manages video |
| Hard Disk | Stores recorded footage |
| Monitor | Displays live video |
| Power Supply | Provides electrical power |
| Cables | Connect system components |
| Router/Switch | Provides network connectivity |

---

# DVR vs NVR

| Feature | DVR | NVR |
|---|---|---|
| Camera Type | Analog Cameras | IP Cameras |
| Video Quality | Standard to HD | High Definition |
| Cabling | Coaxial Cable | Ethernet Cable |
| Installation | Simpler | Advanced |
| Remote Features | Limited | Advanced |

# CCTV Installation Process

## Step 1: Site Survey
- Identify important monitoring areas
- Determine camera positions
- Check lighting conditions

## Step 2: Install Cameras
- Mount cameras securely
- Adjust viewing angles
- Protect outdoor cameras from weather

## Step 3: Connect Cables
- Connect cameras to DVR/NVR
- Connect power supply
- Organize cable routing

## Step 4: Configure Recording System
- Set date and time
- Configure recording schedules
- Enable motion detection

## Step 5: Test System
- Verify live view
- Test recording playback
- Check remote access

# Advantages of CCTV

- Improves security
- Prevents theft and vandalism
- Provides evidence during incidents
- Enables remote monitoring
- Increases workplace safety
- Monitors employee and customer activity

---

# Disadvantages of CCTV

- Installation cost
- Requires maintenance
- Privacy concerns
- Storage requirements
- Network dependency for remote access

---

# CCTV Storage Methods

## Local Storage
Video is stored on DVR/NVR hard disks.

### Advantages
- Fast access
- No internet dependency

### Disadvantages
- Limited storage capacity
- Risk of physical damage

---

## Cloud Storage
Video footage is stored online.

### Advantages
- Remote access
- Better backup protection

### Disadvantages
- Requires internet connection
- Subscription costs

---

# CCTV Maintenance

Regular maintenance helps ensure reliable performance.

## Maintenance Tasks
- Clean camera lenses
- Check cables and connectors
- Verify recording status
- Update firmware
- Inspect power supplies
- Test remote viewing

---

# Basic CCTV Troubleshooting

| Problem | Possible Cause | Solution |
|---|---|---|
| No Video | Power issue | Check power supply |
| Blurry Image | Dirty lens | Clean camera lens |
| No Recording | Full storage | Delete old footage |
| Network Offline | Router issue | Restart network devices |
| Night Vision Not Working | IR LED problem | Check infrared LEDs |

---

# Best Practices for CCTV Security

- Use strong passwords
- Change default login credentials
- Update firmware regularly
- Restrict unauthorized access
- Backup important recordings
- Use encrypted remote access
